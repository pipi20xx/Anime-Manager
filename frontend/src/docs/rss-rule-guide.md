# 下载规则配置 (RSS)

**核心处理文件**: `backend/rss_core/matcher.py` (逻辑位于 `Matcher.check_match` 函数)

下载规则在「订阅页 → 下载规则」标签页管理（「创建新规则」按钮打开「创建匹配规则」/「编辑匹配规则」弹窗）。系统会获取订阅源中的最新条目，然后逐一用您配置的规则对 **RSS 原始标题** 进行比对。只有 **同时满足** 以下条件的资源才会被推送下载：

*   满足「包含关键词」的所有条件
*   不触发「排除关键词」中的任意条件
*   如果指定了「作用范围 (留空则监控所有源)」，则资源必须来自指定的订阅源

> **💡 提示**：
> *   仅当订阅源编辑弹窗中的「下载规则」开关开启时，该源的条目才会进入规则匹配（默认开启）。
> *   订阅源的「前置包含词 / 前置排除词」会在抓取阶段先行过滤，语法与下面的普通关键词模式相同。
> *   命中 TMDB 屏蔽列表的资源在识别后即被标记为已下载，不会进入规则匹配（详见「追剧订阅配置」指引的 TMDB 屏蔽列表一节）。

## 1. 普通关键词模式 (Simple Mode)

适合绝大多数场景。不区分大小写，关键词按**子串包含**判断。

### 包含关键词 (Must Contain)
逻辑结构：**(A 且 B) 或 (C 且 D)**

| 符号 | 含义 | 示例 |
| :--- | :--- | :--- |
| **空格** | **逻辑与 (AND)** | `海贼王 1080p` <br>标题需同时包含 "海贼王" 和 "1080p" |
| **\|** | **逻辑或 (OR)** | `1080p \| 4k` <br>标题含 "1080p" 或 "4k" 均可 |
| **混用** | **组合逻辑** <br>(空格优先级高于 \|) | `海贼王 1080p \| 鬼灭之刃 4k` <br>匹配 (海贼王 AND 1080p) OR (鬼灭之刃 AND 4k) |

### 排除关键词 (Must Not Contain)
即"黑名单"。一旦标题包含以下任意一个词，直接丢弃。

| 写法 | 含义 |
| :--- | :--- |
| `720p` | 只要包含 "720p" 就丢弃 |
| `720p \| MP4` | 既不要 720p，也不要 MP4 格式<br>(用 `\|` 分隔多个排除词，含空格的排除项按完整短语匹配) |

## 2. 正则表达式模式 (Regex Mode)

> **核心提示**：完全支持 Python 标准正则语法（默认开启 `re.I` 忽略大小写）。

此模式下，「包含关键词」和「排除关键词」框内均填写 **一条完整的正则表达式**。

### 实战示例

| 场景 | 正则表达式 | 说明 |
| :--- | :--- | :--- |
| **精确匹配集数** | `[MyGroup].*One Piece.*-\s+\d{3,4}\s+.*1080p` | 匹配组名开头，中间含 One Piece，紧接3-4位集数，最后1080p |
| **限定字幕组** | `(ANi\|Bahamut).*我推的孩子.*1080p` | 只匹配 ANi 或 Bahamut 字幕组发布的资源 |
| **忽略大小写** | `(?i)spy\s?x\s?family.*1080p` | 虽然系统默认忽略大小写，但你仍可显式指定 `(?i)` |

## 3. 规则的其他设置

| 字段 | 说明 |
| :--- | :--- |
| **匹配模式** | 「普通关键词」/「正则表达式」二选一 |
| **作用范围 (留空则监控所有源)** | 限定规则只对选中的订阅源生效，留空则监控所有源 |
| **指定下载器** | 命中后推送到哪个下载客户端，留空使用默认 |
| **保存路径** | 下载保存目录，留空使用客户端默认路径 |
| **分类 / 标签** | 推送时传给下载客户端的 Category / Tags |
| **自动开始 / 添加后暂停** | 种子添加到客户端后是否处于暂停状态 |
| **启用规则** | 规则总开关 |

规则卡片上提供 **「预览」**（用当前已抓取的条目模拟匹配，验证规则效果）与 **「复制」**（基于现有规则快速创建副本）操作；右上角「下载记录」可查看历史推送。
