### 追剧订阅配置指引

追剧订阅是基于 **元数据识别 (Metadata-Driven)** 的自动化追新方案。系统会精准识别 RSS 标题背后的资源属性，并将其**规范化**。订阅在「订阅页 → 追剧订阅」中创建（「添加新订阅」/「Bangumi一键订阅」/「自动RSS订阅管理」）。

> **⚠️ 重要提示**：在设置「匹配条件」或「洗版规则」时，必须使用系统**规范化后的标准名称**（如下表所示），而不是原始文件名里的写法。例如，文件名写着 `2160p`，但在规则里你应该填 `4K`。所有规格字段均为多选下拉：可直接勾选规范值，也可手动输入列表外的值。

## 第一关：基础过滤 (门槛)

在订阅编辑弹窗（「新建订阅」/「编辑订阅」）的 **「匹配条件」** 区设置。这是资源的**准入证**。只有满足此处条件的资源，才有资格进入下一轮比对。

*   **8 个规格字段**（措辞与洗版规则、TMDB 屏蔽列表完全一致）：**分辨率 / 制作组 / 介质来源 / 视频编码 / 音频编码 / 字幕语言 / 视频特效 / 发布平台**，均为多选下拉，**留空 = 不限制**。
*   **必须包含 / 排除关键词**：针对 **RSS 原始标题** 做关键词匹配（**不是正则**）：空格 = 逻辑与 (AND)，`|` = 逻辑或 (OR)；排除词用空格或 `|` 分隔，任一命中即排除。适合过滤 `[v2]`、`[Repack]` 等非标准字段。

> **💡 提示**：同一套「匹配条件」也出现在「订阅预设管理」的预设表单与「自动RSS订阅管理」的探测任务表单中，语义完全一致。

**原则**：建议仅设置最基本的底线（例如：排除关键词填 `720p`），**尽量放宽限制**，以便让更多潜在的好资源进入“洗版池”。

## 第二关：洗版策略 (洗版/优选)

这是资源的**排位赛**。通过 追剧订阅页右上角的 **「洗版规则管理」** 设定，决定谁是最好的版本；再在订阅表单的 **「洗版策略」** 下拉中为每部番剧绑定一个策略。

### 1. 基础规则 (Rules)
在「洗版规则管理」→「基础规则」标签页定义具体的"优质资源"标准：8 个规格字段（与订阅表单同一套措辞，留空表示不限制）+ **必须包含 / 不能包含**（支持正则，针对 RSS 原始标题，忽略大小写）。
*   **规则 A**: 4K原盘 (`分辨率=4K`, `介质来源=Blu-ray, Remux`)
*   **规则 B**: 1080p高质量 (`制作组=LoliHouse, VCB-Studio`)

> **💡 提示**：可点「从预设新建」快速创建常用规则，内置预设：`1080P`、`4K`、`4K HDR`、`4K 原盘/Remux`、`WEB-DL`、`简中字幕`、`繁中字幕`、`无损/全景声音频`、`杜比视界`。

### 2. 策略组装 (Profile)
在「洗版策略」标签页将规则按顺序排列（**洗版排序，上方优先**）并逐条设置**分值**。打分时**按排序取第一条命中规则的分值，无规则命中记 0 分**：
1.  **Tier 1 (1000分)**: [规则 A] 4K原盘
2.  **Tier 2 (800分)**: [规则 B] 1080p高质量
3.  **保底 (0分)**: (未命中任何规则的资源)

### 3. 洗版机制 (Upgrade)
*   **「允许洗版」关闭 (优选模式)**: 每集/电影只下载一次，下载过的资源即使之后出现更高规格的版本也不会重复下载。
*   **「允许洗版」开启 (洗版模式)**: 首次下载不限分值、直接下载，但会把该资源的得分记录下来作为后续比较基准。之后同一集/电影出现新资源时，新资源得分**高于**已记录分值才会重新下载替换（例如从 0分 → 800分）；已下载资源得分达到**截止分值**后不再洗版。

## TMDB 屏蔽列表

入口：订阅页 → **「订阅源」** 标签页 → **「TMDB屏蔽管理」**。命中屏蔽条目的资源，识别后直接标记已下载，**跳过下载规则与追剧订阅**。支持三种粒度：

| 粒度 | 填法 | 效果 |
| :--- | :--- | :--- |
| **整部作品** | 填「TMDB ID」+「类型」，条件全部留空 | 该作品的资源全部拦截，并**同步把启用订阅的对应集标记已下载**（订阅不再追） |
| **作品内资源级** | 填「TMDB ID」+「类型」+ 匹配条件 | 只拦截该作品内满足条件的资源（如某制作组的版本），同作品其他组的资源照常匹配 |
| **全局条件** | 「TMDB ID（可留空）」留空 + 至少一个条件 | 不锚定作品，对所有作品按条件拦截（如屏蔽某制作组的全部发布）；此时「类型」可选 全部/剧集/电影 |

### 可填条件
*   **匹配条件**：分辨率 / 制作组 / 介质来源 / 视频编码 / 音频编码 / 字幕语言 / 视频特效 / 发布平台（与订阅表单同一套字段与措辞，多选下拉，可选规范值也可手输）。
*   **档案条件（按作品 TMDB 档案匹配）**：**流派**、**制作公司**、**关键词**（远程搜索多选，可输入 ID 回车添加）、**原始国家**、**原始语言**（多选）、**名称匹配**、**年份/范围**（手输，年份支持 `2024` 或 `2020-2025`）。字段与二级分类规则完全一致。

### 判定语义
*   匹配条件与档案条件是**与**关系，多个条件需**同时满足**。
*   档案数据来自数据中心（作品 TMDB 深度档案），**档案特征缺失按不匹配处理**。
*   锚定作品的条目按 TMDB ID + 类型去重（同一作品只能有一条）；全局条件条目允许多条并存。
*   命中后写入下载记录（来源显示为「TMDB屏蔽列表」）；屏蔽在识别后立即生效，对已识别的历史条目也会回溯补拦。

## 🎯 最佳实践：宽进严出

如果您希望实现：**“先随便下个 ANi 看，过两天出了 DMG 就洗成 DMG”**。

❌ **错误配置**：
*   订阅过滤：制作组 = `ANi` (错！这会直接把 DMG 拒之门外)

✅ **正确配置**：
*   **订阅过滤**：制作组 **留空** (允许任何人进门)。
*   **洗版策略**：
    *   **Tier 1**: 制作组=`DMG` (1000分)
    *   **Tier 2**: 制作组=`ANi` (800分)

这样，系统就能在第一时间下载 ANi (800分)，等 DMG (1000分) 出来后，因为 `1000 > 800`，自动触发洗版。
