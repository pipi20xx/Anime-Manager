# 自定义特权规则 (Privileged Rules)

**核心处理文件**: `backend/recognition_engine/special_episode_handler.py`

特权规则是**优先级最高**的提取规则，在识别流程的最早期执行。命中后：
- **集数直接锁定**，不会被后续流程覆盖
- **标题作为优先搜索候选**，提高匹配准确率
- 提供 `tmdbid` 时**直接按 ID 匹配**，跳过标题搜索

---

## 🎯 规则格式

```
正则表达式 => {[字段=值;字段=值;...]} # 规则描述（可选）
```

- 匹配方式为 `re.search`，**忽略大小写**，不要求匹配整个文件名（用 `^` / `$` 自行控制边界）
- 整行以 `#` 开头是注释，会被忽略；规则行尾 `#` 之后的内容作为规则描述，显示在识别日志中
- 使用 ` => {[...]}` 定义提取字段，支持捕获组引用（`\1`, `\2`）；`=>` 两侧必须保留空格，字段块必须写成 `{[...]}`，字段间用 `;` 分隔，字段名不区分大小写（解析时统一转小写）
- 规则行中的 `#` 一律作为描述分隔符处理，正则里包含 `#` 会导致规则被截断

| 字段 | 说明 | 示例 |
| :--- | :--- | :--- |
| **group** | 字幕组名称 | `group=\1` |
| **title** | 标题（**必填**，见下方说明） | `title=\2` |
| **e** | 集数（纯数字） | `e=\3` |
| **s** | 季数（纯数字） | `s=\1` |
| **tmdbid** | TMDB ID（纯数字） | `tmdbid=56559` |
| **type** | 媒体类型 | `type=tv` / `type=movie` / `type=auto` |
| **year** | 年份（纯数字） | `year=2023` |

**title 必填：** 每条规则都必须提取出有效标题（解析后长度 ≥ 2 个字符），否则整条规则会被跳过、继续尝试下一条。即使只想锁定 TMDB ID，也要提供 `title`（可以是不带捕获组的固定文本）。`e` / `s` / `tmdbid` / `year` 的值（捕获组解析后）必须是纯数字，否则该字段不生效。

**type 字段说明：**
- `type=tv` - 强制使用 TV 接口搜索
- `type=movie` - 强制使用 Movie 接口搜索
- `type=auto` - 同时搜索 TV 和 Movie，根据 TMDB 返回结果自动判断类型

**示例：**
```
# 标准格式：[字幕组] 标题 - 集数
^\[([^\]]+)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3]}

# 直接锁定 TMDB ID（title 必填，可写固定文本）
^Yami\.Shibai\.S(\d{2})E(\d{2,3}) => {[title=Yami Shibai;tmdbid=56559;type=tv;s=\1;e=\2]}

# 电影格式：只提取标题
^\[([^\]]+)\]\s+(.+?)\s+\[BD\] => {[group=\1;title=\2]}

# 自动类型判断：同时搜索 TV 和 Movie
^\[([^\]]+)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3;type=auto]}

# 行尾 # 后是规则描述，会显示在识别日志中
^\[(LoliHouse)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3]} # LoliHouse 定向
```

## 📝 常用规则模板

### 1. 标准格式 `[字幕组] 标题 - 集数`

**文件名示例：**
```
[LoliHouse] Goumon Baito-kun no Nichijou - 08 [WebRip 1080p].mkv
[MILKs&LoliHouse] Saioshi no Gikei - 12 [WebRip 1080p].mkv
```

**规则：**
```
^\[([^\]]+)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3]}
```

**解析：**
| 正则部分 | 说明 |
| :--- | :--- |
| `^\[([^\]]+)\]` | 匹配开头的 `[字幕组]`，捕获组 1 |
| `\s+` | 匹配空格 |
| `(.+?)` | 非贪婪匹配标题，捕获组 2 |
| `\s+-\s+` | 匹配 ` - ` |
| `(\d{1,4})` | 匹配 1-4 位集数，捕获组 3 |

---

### 2. 括号集数格式 `[字幕组] 标题 [集数]`

**文件名示例：**
```
[SweetSub] Mononoke - The Ashes of Rage [05][BDRip].mp4
```

**规则：**
```
^\[([^\]]+)\]\s+(.+?)\s+\[(\d{1,4})\] => {[group=\1;title=\2;e=\3]}
```

---

### 3. 指定字幕组定向规则

**文件名示例：**
```
[LoliHouse] Title - 01 [WebRip].mkv
```

**规则：**
```
^\[(LoliHouse)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3]}
```

---

### 4. 合作字幕组规则

**文件名示例：**
```
[NC-Raws & LoliHouse] Title - 01 [WebRip].mkv
```

**规则：**
```
^\[(.*?LoliHouse.*?)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3]}
```

---

### 5. 无字幕组格式 `标题 - 集数`

**文件名示例：**
```
Title Name Here - 08 [1080p].mkv
```

**规则：**
```
^([^\[\]]+?)\s+-\s+(\d{1,4}) => {[title=\1;e=\2]}
```

---

### 6. 带副标题格式 `[字幕组] 标题 [集数_副标题]`

**文件名示例：**
```
[晚街与灯] Title [05_大海啸].mkv
```

**规则：**
```
\[(晚街[與与]燈)\]\s*(.+?)\s*\[(\d{1,3})(?:\s*[-_][^\]]*)?\] => {[group=\1;title=\2;e=\3]}
```

---

### 7. 仅标题提取 (电影/剧场版)

适用于电影、剧场版等无集数的资源，只提取标题作为优先搜索词。

**文件名示例：**
```
[MyGroup] Movie Name [BDRip].mkv
[MovieGroup] Anime Movie [BD 1080p].mp4
```

**规则：**
```
^\[([^\]]+)\]\s+(.+?)\s+\[BD\] => {[group=\1;title=\2]}
```

**效果：**
- 标题作为优先搜索候选
- 集数由后续流程（Anitopy）处理
- 日志显示 `集数: 未锁定 (仅标题提取)`

---

### 8. 高级示例：直接锁定 TMDB ID 和类型

**文件名示例：**
```
Yami.Shibai.S01E02.Some.Title.1080p.WEBRip.x264.mkv
Yami.Shibai.S03E05.Another.Title.720p.WEBRip.AAC.mkv
```

**规则：**
```
^Yami\.Shibai\.S(\d{2})E(\d{2,3}) => {[title=Yami Shibai;tmdbid=56559;type=tv;s=\1;e=\2]}
```

**效果：**
- 直接锁定 TMDB ID 为 56559，匹配阶段跳过标题搜索，按 ID 直接拉取详情
- 媒体类型为 TV
- 季数和集数从捕获组提取
- `title` 为必填字段：ID 已锁定时标题不再参与搜索，写固定文本即可

---

### 9. 多字段组合示例

**文件名示例：**
```
[MyGroup] Anime Title 2023 - 12 [1080p].mkv
```

**规则：**
```
^\[([^\]]+)\]\s+(.+?)\s+(\d{4})\s+-\s+(\d{1,4}) => {[group=\1;title=\2;year=\3;e=\4]}
```

**效果：**
- 提取字幕组、标题、年份、集数
- 所有字段都可用于后续匹配

## 🔧 正则编写指南

### 捕获组引用说明

正则中用 `()` 包围的部分是捕获组，索引从 1 开始：

```
^\[([^\]]+)\]\s+(.+?)\s+-\s+(\d{1,4})
   ↓        ↓          ↓
  组(1)    组(2)      组(3)
  字幕组    标题       集数
```

在规则中使用 `\1`, `\2`, `\3` 引用这些捕获组：

```
=> {[group=\1;title=\2;e=\3]}
```

引用不存在的捕获组时，`\数字` 会原样保留在字段值中。

### 常用正则模式

| 模式 | 说明 | 示例 |
| :--- | :--- | :--- |
| `\[` | 匹配 `[` (需转义) | `^\[` 匹配开头 `[` |
| `\]` | 匹配 `]` (需转义) | `[^\]]+` 匹配非 `]` 字符 |
| `\s+` | 匹配一个或多个空格 | `\s+-\s+` 匹配 ` - ` |
| `\d{1,4}` | 匹配 1-4 位数字 | 集数提取 |
| `(.+?)` | 非贪婪匹配任意字符 | 标题提取 |
| `[^\]]+` | 匹配非 `]` 的任意字符 | 字幕组提取 |
| `(?:\s|\[|$)` | 非捕获组，匹配空格/`[`/结尾 | 结束边界 |
| `(?:v\d)?` | 可选的版本号 | 匹配 `v2` 等 |

### 边界匹配技巧

| 需求 | 写法 |
| :--- | :--- |
| 匹配开头 | `^` |
| 匹配结尾 | `$` |
| 集数后是空格或 `[` | `(?:\s|\[|$)` |
| 可选版本号 `v2` | `(?:v\d)?` |


## ⚠️ 注意事项

### 1. 规则优先级

规则按**从上到下**的顺序匹配，第一条命中的规则生效。建议：
- 特定字幕组规则放在前面
- 通用规则放在后面

### 2. 标题验证

`title` 是必填字段，提取的标题必须满足：
- 长度 ≥ 2 个字符
- 不能为空

不满足时**整条规则被跳过**（继续尝试下一条规则），而不是只忽略标题字段。

### 3. 集数锁定

特权提取的集数**不可被覆盖**，后续流程（Anitopy、合集增强等）都会跳过集数处理。命中时，集数原文与字幕组名还会自动从后续搜索用的清洗标题中剥离，避免污染搜索词。

### 4. 标题尾部季号自动剥离

规则未显式提供 `s` 时，若标题以季号结尾（如 `Title S2`、`Title Season 2`、`标题 第二季`），系统会自动把季号从标题中剥离并作为季数使用，避免季号混入搜索词。季号须为 1-2 位数字，与标题之间以空格/`.`/`_`/`-` 分隔（`第 N 季` 写法允许空格），且剥离后剩余标题至少 2 个字符，否则不剥离。

### 5. 多语言标题

如果标题包含 `/`（如 `中文标题 / English Title`），系统会自动拆分为多个搜索词依次搜索。

### 6. 捕获组引用

- 使用 `\1`, `\2` 引用正则捕获组
- 索引从 1 开始
- 确保引用的捕获组存在（不存在的引用会原样保留在值中）

## 🚀 使用方式

### 方式一：前端配置

在 **系统设置 → 识别与订阅规则 → 自定义特权规则** 的 **本地规则**（可编辑）中输入规则，每行一条，点击 **保存全部修改** 生效。

### 方式二：远程订阅

创建纯文本文件托管在服务器：

```
# 这是注释，会被忽略
^\[([^\]]+)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3]}

# LoliHouse 定向
^\[(LoliHouse)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3]}

# Yami.Shibai 特殊格式
^Yami\.Shibai\.S(\d{2})E(\d{2,3}) => {[title=Yami Shibai;tmdbid=56559;type=tv;s=\1;e=\2]}
```

然后在 **远程订阅**（仅同步）中填入文件地址（每行一个 URL），点击 **同步远程规则** 即可。远程规则与本地规则合并生效。

### 方式三：识别测试页临时注入

在识别测试页的 **临时规则注入（仅本次生效）→ 自定义特权规则** 文本框中输入规则，仅对当次测试生效，不会被保存。

## 💡 最佳实践

### 1. 规则排序

```
# 1. 最具体的规则（特定字幕组）
^\[(LoliHouse)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3]}

# 2. 中等具体规则（特定格式）
^\[([^\]]+)\]\s+(.+?)\s+\[(\d{1,4})\] => {[group=\1;title=\2;e=\3]}

# 3. 通用规则（放在最后）
^\[([^\]]+)\]\s+(.+?)\s+-\s+(\d{1,4}) => {[group=\1;title=\2;e=\3]}
```

### 2. 使用 TMDB ID 提高准确率

对于已知的作品，直接锁定 TMDB ID（`title` 必填，可写固定文本）：

```
^Yami\.Shibai\.S(\d{2})E(\d{2,3}) => {[title=Yami Shibai;tmdbid=56559;type=tv;s=\1;e=\2]}
```

### 3. 组合多个字段

```
^\[([^\]]+)\]\s+(.+?)\s+(\d{4})\s+-\s+(\d{1,4}) => {[group=\1;title=\2;year=\3;e=\4]}
```

### 4. 测试规则

在识别测试页通过 **临时规则注入** 输入规则并识别文件名，从日志的 `[规则][特权]` 输出确认是否命中；也可以调用 `POST /api/privilege/test` 接口测试规则提取的集数。
